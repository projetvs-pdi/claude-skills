# Formatos e dimensões por canal

Referência rápida para configurar o tamanho correto ao gerar a peça no Canva (ou informar ao Claude Design/Gamma). Confirme com o usuário se ele precisa de um tamanho fora desta lista — plataformas mudam especificações com frequência, então trate isto como ponto de partida, não fonte definitiva.

## Redes sociais

| Peça | Dimensão (px) | Proporção |
|---|---|---|
| Instagram feed (quadrado) | 1080 x 1080 | 1:1 |
| Instagram feed (retrato) | 1080 x 1350 | 4:5 |
| Instagram/Facebook Story | 1080 x 1920 | 9:16 |
| Instagram Carrossel | 1080 x 1080 (por slide) | 1:1 |
| Facebook post (feed) | 1200 x 630 | ~1.91:1 |
| LinkedIn post (feed) | 1200 x 1200 | 1:1 |
| LinkedIn banner de página | 1584 x 396 | ~4:1 |
| X/Twitter post | 1600 x 900 | 16:9 |
| YouTube thumbnail | 1280 x 720 | 16:9 |
| Pinterest pin | 1000 x 1500 | 2:3 |

## Anúncios

| Peça | Dimensão (px) | Observação |
|---|---|---|
| Meta Ads (feed) | 1080 x 1080 | Mesma base do post de feed |
| Meta Ads (story/reels) | 1080 x 1920 | Vertical, tela cheia |
| Google Display (banner padrão) | 300 x 250 | Retângulo médio, o mais usado |
| Google Display (leaderboard) | 728 x 90 | Topo de página |

## Impressos / outros

| Peça | Dimensão | Observação |
|---|---|---|
| Flyer/pôster A4 | 210 x 297 mm | Padrão para impressão |
| Cartão de visita | 90 x 50 mm (BR) | Confirmar padrão do país do usuário |
| Capa de e-book/documento | 1600 x 2000 px | Proporção retrato ~4:5 |

## Como aplicar

- Ao usar Canva, passe a dimensão certa para a ferramenta de geração (`generate-design`/`create-design-from-brand-template`) em vez de aceitar um tamanho genérico.
- Ao usar Claude Design (canvas), informe a proporção/tamanho do artboard na hora de montar a peça.
- Ao usar Gamma, dimensões não se aplicam da mesma forma — a ferramenta define o layout por slide/página automaticamente.
