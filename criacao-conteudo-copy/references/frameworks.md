# Frameworks de Copywriting

Cada framework organiza a mesma coisa — atenção, tensão, resolução, ação — de um jeito diferente. Escolha pelo formato e pelo nível de consciência do público (Passo 3 do SKILL.md), não por preferência pessoal.

## PAS — Problema → Agitar → Solução

1. **Problema:** nomeie a dor específica que o leitor já sente, na linguagem dele.
2. **Agitar:** aprofunde a consequência de não resolver — o que continua acontecendo, o custo de esperar.
3. **Solução:** apresente a oferta como a saída natural, ligada diretamente ao que foi agitado.

Melhor para: anúncios, posts curtos, e-mails de venda direta, público que já sente o problema mas não busca ativamente uma solução ainda.

Risco comum: agitar demais sem oferecer alívio rápido soa manipulador — mantenha a proporção equilibrada com o tamanho da peça.

## AIDA — Atenção → Interesse → Desejo → Ação

1. **Atenção:** headline ou abertura que interrompe o scroll/leitura.
2. **Interesse:** desenvolve com um ângulo relevante para quem já parou para ler.
3. **Desejo:** conecta a oferta a um resultado que o leitor quer.
4. **Ação:** CTA claro.

Melhor para: home de site institucional, posts de awareness, campanhas onde o público ainda não tem consciência clara do problema.

## BAB — Antes → Depois → Ponte

1. **Antes:** descreve a situação/dor atual do leitor (ou de um cliente real, em um case).
2. **Depois:** descreve o estado desejado, como se já tivesse acontecido.
3. **Ponte:** a oferta é o que liga um ao outro.

Melhor para: testemunhos, cases de sucesso, e-mails de prova social, qualquer peça que já tenha um resultado real para mostrar (não invente o "depois" se não houver prova — nesse caso, use PAS ou AIDA em vez de fabricar um resultado).

## 4 Ps — Promessa → Retrato → Prova → Chamada

1. **Promessa:** o resultado principal, direto.
2. **Retrato:** pinta a cena de como é viver esse resultado.
3. **Prova:** dados, depoimentos, números, garantias — o que sustenta a promessa.
4. **Chamada:** CTA.

Melhor para: páginas de vendas e de serviço com prova concreta disponível. Sem prova real, este framework fica fraco — prefira PAS/AIDA e seja honesto sobre a ausência de prova social ainda.

## QUEST — Qualificar → Entender → Educar → Estimular → Transição

1. **Qualificar:** deixa claro para quem é o conteúdo (e implicitamente, para quem não é).
2. **Entender:** demonstra que entende o contexto/problema do leitor em profundidade.
3. **Educar:** ensina algo genuinamente útil, não só "gancho para vender".
4. **Estimular:** conecta o que foi ensinado ao desejo de resolver.
5. **Transição:** leva para a oferta sem uma virada abrupta.

Melhor para: artigos de blog, newsletters de conteúdo, e-mails de nutrição/aquecimento — qualquer peça longa onde o objetivo principal ainda não é a venda direta.

## Combinando frameworks

Uma peça pode abrir com a lógica de um framework e fechar com outro — por exemplo, um post no estilo PAS que termina com uma chamada no formato "Promessa + Prova" dos 4 Ps. O framework é uma lente para organizar a lógica argumentativa, não um checklist rígido de seções obrigatórias.
